# Spawn SDK

Keep transport and save contracts small and explicit. This is a first-party, same-origin prototype; only `rob-the-rich` is enabled. Do not broaden origins or accept arbitrary game IDs without server-enforced game-scoped authorization. Never expose platform cookies, wallet keys, token minting or reward issuance to games.

Keep frontend rendering, game rules and authoritative server logic separate in examples. Describe implemented behavior separately from planned capabilities. Run `npm test`, `npm run check` and `npm run build` before changes are accepted. Update README and integration notes when behavior changes. No npm publication is authorized by a GitHub push.
